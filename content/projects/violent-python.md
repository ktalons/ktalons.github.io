A curated collection of my Python scripting assignments from cyber operations coursework — informally named for the canonical *Violent Python* book by TJ O'Connor. Covers the standard pen-tester's scripting toolkit:

- Network scanning and recon scripts
- Packet crafting and analysis
- File and protocol parsing
- Credential / hash handling exercises
- Light offensive automation

Used as a workbench to practice the kinds of scripts a SOC analyst or detection engineer ends up writing in production — quick parsers, indicator extractors, helper one-liners.
